## 가르치는 방식

**할 수 있는 것**과 **할 수 없는 것**을 먼저 그립니다. AI는 만능이 아니라 도구이고, 도구를 잘 쓰려면 한계부터 알아야 한다는 게 제 신조예요.

수업은 항상 "오늘 끝나면 동작하는 무언가가 손에 남는다"를 목표로 합니다. 라이브러리 설명만 한 시간 듣는 수업이 싫었던 경험에서 만든 원칙이에요.

## 다루는 스택

- **에이전트**: Claude Agent SDK, MCP, Cursor / Claude Code
- **백엔드**: Next.js, Cloudflare Workers, Supabase, PostgreSQL
- **프론트엔드**: React, TypeScript, Tailwind, shadcn/ui
- **인프라**: Vercel, Cloudflare, AWS Lambda
